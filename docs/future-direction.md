# Future Direction

UCF-RS should grow along these axes without weakening the current authority model:

1. Editor adapters that send real edit deltas and render overlays.
2. Offline operation queues with base-epoch reconciliation.
3. Remote server mode with project-local deterministic exports.
4. Evidence archive policy for teams that explicitly want raw replay data.
5. Brownfield adoption tools that propose evidence without accepting it implicitly.

Reqtrace should remain the compact v2.1.7 grep-native convention. UCF-RS carries
the forward-looking overlay/server architecture.
